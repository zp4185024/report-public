# 全局数据资源与报表参数验证结果

## 验证范围

本轮解决“查询参数固定、数据来源固定”以及“数据源/数据集错误隶属于单张报表”的问题，完成全局资源复用闭环：

- `/data-assets` 独立页面统一管理 SQL Server 数据源和数据集；
- 数据源和数据集支持新增、编辑、启停和独立修订号，密码只写不读；
- 数据集维护参数化只读 `SELECT/WITH` SQL、自动识别参数和字段结构；
- 数据集编辑区可用当前草稿 SQL 和参数执行最多 50 行预览，不保存草稿；
- 报表通过 `DatasetCode` 引用全局数据集，不再保存或修改连接信息和 SQL；
- 查询参数可新增、删除、排序，并配置类型、来源、控件、默认表达式、必填和 URL 预填；
- 数据集字段可新增、删除并配置类型、列宽和公式模板；报表字段页只读展示；
- 报表预览、数据集草稿预览、普通导出和大文件导出读取同一份数据库配置；
- 报表、数据源和数据集保存分别使用修订号做乐观并发检查。

本轮不包含单张报表多主数据集、参数级联选项、配置发布审批和历史版本回滚。

## 安全边界

- SQL 文本只接受单条 `SELECT/WITH`，拒绝注释、多语句、临时表、DML、DDL、`EXEC` 和外部数据源入口。
- 数据集保存时从已清理 SQL 中提取 `@参数名`；报表保存时要求对应参数已定义，运行时使用 `SqlParameter` 绑定，不拼接输入值。
- `Fixed/System` 参数拒绝客户端覆盖；参数按配置类型转换后才进入数据库命令。
- 配置读取只返回 `passwordConfigured`，不返回连接串或密码。
- 配置、连接测试、动态查询和导出入口使用 `SuppressMonitor`，不把密码、查询参数或数据结果写入 Admin.NET 请求监控日志。
- 数据源查询有连接超时、命令超时和最大行数限制；数据集草稿预览额外限制为最多 50 行、最长 30 秒。

静态 SQL 校验不是数据库权限控制的替代品。正式数据源必须使用单独的只读账号，并限制到允许查询的库、视图或存储副本。

## 上线前缺口

1. `PocReportApi` 当前仍为本地核心验证入口，类级别带 `AllowAnonymous`。正式环境必须把报表配置、资源列表、资源保存和连接测试迁入管理员鉴权接口，并记录不含密码、SQL 参数值和查询结果的审计事件。
2. `RcDataSource.ConnectionString` 当前用于验证闭环。正式环境必须改为凭据加密或外部密钥引用，禁止普通数据库查询者读取连接凭据。
3. 当前可创建多个全局数据集，但单张报表只有一个主数据集引用；主从关系、下拉选项数据集和参数级联仍未实现。
4. 配置只有当前修订号并发保护，没有草稿、发布、审批和历史回滚。上线前至少要区分“编辑中”和“已发布”。
5. 现有模板的“序号/科室”两个明细标记与表头位置相反，这是本轮之前已存在的模板数据问题，需要单独修正保存模板，不属于数据源和参数配置代码。

数据库迁移不删除表或业务数据，但不提供自动结构回滚。若功能需要撤回，先停止新接口使用并导出 4 张配置表；恢复旧索引和列约束必须由数据库负责人审核脚本并在备份后执行。
