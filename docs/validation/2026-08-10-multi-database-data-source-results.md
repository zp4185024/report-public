# 多数据库数据源验证结果

## 实现范围

全局数据源不再固定为 SQL Server，当前支持：

| 数据库类型 | 默认端口 | 数据库字段含义 | 驱动 |
| --- | ---: | --- | --- |
| SQL Server | 1433 | 数据库名 | `Microsoft.Data.SqlClient` |
| Oracle | 1521 | 服务名 | `Oracle.ManagedDataAccess.Core` |
| MySQL | 3306 | 数据库名 | `MySqlConnector` |
| PostgreSQL | 5432 | 数据库名 | `Npgsql` |

连接串构造、脱敏回读、密码保留规则、连接测试、类型化参数、数据集预览、报表查询和分页语法统一由 `PocDatabaseProvider` 管理。切换数据库类型或修改服务器、端口、数据库、用户名时必须重新输入密码。

## 安全边界

- API 不返回连接串或密码，只返回 `passwordConfigured`。
- 新数据源、切换数据库类型或改变连接端点时必须重新输入密码。
- SQL 仍只允许单条参数化 `SELECT/WITH`；静态校验不能替代数据库只读权限。
- 生产数据库接入、账号授权和网络放行必须由负责人审核，并保留回滚到原数据源配置的能力。
