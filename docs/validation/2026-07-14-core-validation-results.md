# 报表中心核心验证结果

验证日期：2026-07-14，2026-07-15 补充可编辑模板与全量数据导出验证

验证范围：固定“科室工作量统计”报表、URL 参数、服务器默认日期、模板定义分页、Univer Web Worker 公式、普通 Excel 导出、10 万行异步大文件导出。

## 结论

核心路线可行：React + Univer OSS 0.25.1 能在 Worker 中计算当前页公式；后端固定数据能按模板的 20 行分页返回；普通和大文件导出都能保留公式，并由 Excel/WPS 打开时自动完整计算。

大文件导出不能只把“用了 `OpenXmlWriter`”当作低内存保证。实测 Open XML SDK 包层仍会缓存工作表部件。改为 `ZipArchive + XmlWriter` 真流式写入后，10 万行任务的工作集峰值增量从约 266 MB 降到约 62 MB。

测试环境为本机 Release 后端、Vite 开发服务器和 Playwright Chromium。接口数据为 20 次热调用；时间仅用于本次技术验证，不代表生产容量承诺。
