# Univer 模板 XLSX 导入导出验证设计

## 目标

为当前 `dept-workload` 验证页面增加最小可用的 Excel 模板导入导出闭环：

1. 将当前设计模式中的 Univer 工作簿草稿导出为 `.xlsx`。
2. 将该 `.xlsx` 重新导入为 Univer `IWorkbookData` 草稿。
3. 在页面中继续编辑、保存、刷新和预览。
4. 验证常用公式、样式、合并、行高和列宽能够双向保留。

本轮验证模板交换能力，不替换现有普通数据导出和大文件导出。

## 参考与实现原则

参考 `zhangji261/univer-import-export` 的后端双向转换结构，但不复制该项目代码。该项目没有提供有效的许可证文件，本项目使用 .NET 8 独立实现。

转换器以当前实际使用的 Univer `0.25.1` 类型定义为准，不以参考项目使用的 Univer `0.15.4` 数据结构为准。

## 技术方案

- 前端继续使用现有 React、Vite 和 Univer `0.25.1`。
- 后端使用 ClosedXML 读取和写入 `.xlsx`。
- Excel 与 Univer 之间通过独立的双向转换服务完成。
- 转换结果仍是完整 Univer `IWorkbookData` JSON，沿用现有模板校验和保存流程。
- 后台不计算模板公式；页面预览由 Univer Worker 计算，导出的 Excel 由 Excel/WPS 打开后重新计算。

## 数据库映射表

所有可配置映射规则存放在一张表 `RcPocExchangeMapping` 中，每项映射一条记录。

| 字段 | 含义 |
| --- | --- |
| `UniverVersion` | 适用的 Univer 版本，本轮为 `0.25.1` |
| `MappingVersion` | 同一 Univer 版本下的映射修订版本 |
| `RuleCode` | 规则唯一编码 |
| `Direction` | `ExcelToUniver` 或 `UniverToExcel` |
| `Category` | `Workbook`、`Sheet`、`Cell`、`Style`、`Formula`、`Row`、`Column` |
| `SourcePath` | 来源字段或属性路径 |
| `TargetPath` | 目标字段或属性路径 |
| `TransformType` | `Direct`、`Boolean01`、`Enum`、`Scale`、`Color`、`AddPrefix`、`RemovePrefix` 等通用转换类型 |
| `SourceValue` | 枚举映射的来源值，可空 |
| `TargetValue` | 枚举映射的目标值，可空 |
| `Factor` | 行高等数值换算系数，可空 |
| `IsRequired` | 缺失时是否阻止转换 |
| `IsEnabled` | 是否启用该规则 |
| `Sort` | 规则执行顺序 |
| `Remark` | 调试说明 |

唯一索引为 `UniverVersion + MappingVersion + RuleCode`。运行时选择当前 Univer 版本下最大的映射版本，并读取其中所有启用规则。

这里的当前 Univer 版本来自应用构建配置和后端交换配置，不能直接信任旧模板快照中可能过期的 `appVersion` 字段。

当前 `0.25.1` 的默认规则在表为空时自动写入本地验证数据库。调试人员可以直接修改、启用或停用单条记录，不需要重新编译。转换错误和警告必须包含 `RuleCode`。

正式配置仍使用 Admin.NET 主数据库连接，实体和存储代码同时兼容 SQL Server 与 SQLite。

## 映射范围

### 单元格

| Excel | Univer |
| --- | --- |
| 文本、数字、布尔值 | `v`、`t` |
| 普通 A1 公式 | `f` |
| 单元格样式 | `s` 与工作簿 `styles` 字典 |

Excel 日期按数值序列和数字格式导入，禁止转成固定显示文本。

### 样式

本轮支持：

- 字体名称、字号、粗体、斜体、下划线和删除线。
- 字体颜色和纯色填充。
- 上、下、左、右边框的线型和颜色。
- 水平对齐、垂直对齐、自动换行和文字旋转。
- 数字、日期、百分比和自定义数字格式。
- 合并单元格、行高、列宽、隐藏行列和冻结区域。

样式使用规范化内容生成稳定样式编号，相同样式只在 `styles` 字典保存一次，单元格通过 `s` 引用。

### 公式

- Excel 导入时读取 A1 公式，确保写入 Univer 的 `f` 时以 `=` 开头。
- Univer 导出时移除 ClosedXML API 不需要的开头 `=`，公式主体保持不变。
- 普通单元格引用、跨工作表引用和当前验证使用的 `SUM`、`AVERAGE`、`IF`、`IFERROR` 作为必须通过项。
- 不支持的函数保留公式文本并返回警告，不在后台伪造计算结果。
- 导出工作簿设置为打开时自动完整重算。

## 不支持范围

本轮不处理：

- `.xls`、CSV、ODS。
- 图片、图表、批注、数据验证、数据透视表。
- 宏、VBA、OLE、外部工作簿链接。
- 任意复杂 Excel 文件的百分之百无损往返。
- 把当前分页预览数据导出为模板文件。

## HTTP 接口

### 导入模板

`POST /api/report-center/poc/{reportCode}/template/import-xlsx`

- 使用 `multipart/form-data` 上传一个 `.xlsx` 文件。
- 限制文件大小和有效单元格数量。
- 返回转换后的工作簿快照、所用映射版本和警告列表。
- 不直接写入模板表。

### 导出模板

`POST /api/report-center/poc/{reportCode}/template/export-xlsx`

- 请求体为当前设计草稿快照。
- 返回 `.xlsx` 文件流。
- 响应头包含映射版本；转换警告写入结构化日志。

## 页面操作

- 模板设计模式工具区增加“导入模板”和“导出模板”图标按钮。
- 导入使用隐藏文件选择器，只接受 `.xlsx`。
- 导入前若当前草稿已修改，必须明确确认是否替换。
- 导入成功后替换设计草稿并标记为未保存；用户点击现有“保存模板”后才写数据库。
- 导出始终读取当前设计草稿，包括尚未保存的编辑内容。
- 预览模式禁用模板导入导出按钮，避免与数据结果导出混淆。

## 错误处理

- 文件类型、文件大小、工作表数量和有效单元格数量在转换前校验。
- 必要映射缺失或重复时拒绝转换，并返回对应 `RuleCode`。
- 可选样式无法转换时保留其它内容并返回警告。
- 导入失败不得替换当前草稿。
- 导出失败不得生成空文件或损坏文件。
- 所有转换错误使用中文用户提示，不返回数据库连接串和服务端堆栈。

## 实际验证

使用当前数据库中的 `dept-workload` 模板完成以下闭环：

1. 页面加载当前 revision 的模板。
2. 导出为 `.xlsx`。
3. 后端使用 ClosedXML 重新打开导出文件，确认文件有效。
4. 将导出文件重新导入页面。
5. 对比工作表、公式、样式、合并、行高、列宽和冻结区域。
6. 在导入草稿中编辑一个标题或公式并保存。
7. 刷新页面确认数据库恢复正确。
8. 执行数据预览，确认参数绑定、明细展开和公式计算没有回归。

## 自动化测试

- 映射表首次使用时写入默认规则，再次使用不得重复插入。
- 映射版本选择、停用规则、必要规则缺失和枚举转换测试。
- 当前种子模板的 Univer -> XLSX -> Univer 语义往返测试。
- Excel 文件可被 ClosedXML 重新打开，公式文本和打开重算设置正确。
- 导入文件大小、类型和有效单元格数量限制测试。
- 前端导入成功、导入失败、未保存确认和导出下载测试。
- 浏览器验证导入、导出、保存、刷新和预览完整流程，控制台无新增错误。

## 验收标准

- 当前模板能够下载为 Excel/WPS 可打开的 `.xlsx`。
- 该文件重新导入后能够在 Univer 中正常显示和编辑。
- 当前验证范围内的公式、样式、合并、行高、列宽和冻结区域正确保留。
- 导入后的模板可以保存到数据库并在刷新后恢复。
- 预览仍能展开后台明细并由 Univer Worker 计算公式。
- 映射规则确实来自 `RcPocExchangeMapping`，单条规则修改后无需重新编译即可影响下一次转换。
